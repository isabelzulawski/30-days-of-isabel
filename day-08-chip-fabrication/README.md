# IC fabrication

A minimal black-background walkthrough of silicon wafer preparation, pattern transfer, transistor formation, interconnects, testing, die separation, and packaging. Use the stage buttons or arrow keys to navigate. There is no autoplay.

Open index.html in a browser or serve this folder with a static web server. Google Fonts supplies the interface fonts when online.

The diagrams are conceptual and not to scale. Stages 2–7 illustrate one pattern-transfer loop. Transistor and wiring stages are separate later snapshots after many additional process cycles. The transistor is a simplified planar MOS example. Cleaning, measurement, inspection, and polishing recur throughout real fabrication. The package illustration uses schematic bond wires for a single die.
